# Crust & Co. — Website bán pizza

Website tĩnh được xây dựng bằng HTML5 và CSS thuần cho bài kiểm tra Thiết kế Web.

## Cấu trúc
- `index.html`: nội dung và cấu trúc semantic HTML5.
- `style.css`: CSS Variables, Flexbox/Grid, responsive, hover/focus và animation CSS.
- `PROMPT_LOG.md`: nhật ký Prompt Engineering.

## Chạy thử
Mở `index.html` bằng trình duyệt. Ảnh và Google Fonts sử dụng nguồn trực tuyến nên cần Internet để hiển thị đầy đủ.

## Đưa lên GitHub Pages
1. Tạo repository công khai theo mẫu tên giảng viên yêu cầu: `Ten_Ho_MSSV`.
2. Tải `index.html`, `style.css`, `PROMPT_LOG.md` và thư mục `assets/` (nếu bổ sung ảnh) lên repository.
3. Vào **Settings → Pages**.
4. Chọn nhánh `main` và thư mục `/ (root)`, sau đó lưu.
5. Đợi GitHub Pages xuất bản và thêm URL live vào phần mô tả repository.

## Lưu ý
Đây là website demo tĩnh. Các liên kết đặt hàng mở ứng dụng email; chưa có giỏ hàng, xử lý thanh toán hoặc lưu đơn hàng thật. Đề gốc có nhắc Animate.css và AOS, nhưng phiên bản này chỉ dùng HTML/CSS thuần theo giới hạn công nghệ đã nêu.
